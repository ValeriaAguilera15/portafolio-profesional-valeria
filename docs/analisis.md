# Análisis del portafolio

## Objetivo
Crear un portafolio web personal para mostrar mis proyectos y habilidades como estudiante de desarrollo web.

## Público objetivo
- Profesores
- Compañeros
- Reclutadores junior

## ¿Quién soy?
Soy estudiante de Ingeniería en Informática y estoy aprendiendo desarrollo web con HTML, CSS y JavaScript. Me interesa el desarrollo frontend y la creación de interfaces web.

## ¿Qué quiero mostrar?
- Proyectos académicos y ejercicios
- Mi progreso en desarrollo web
- Mis habilidades técnicas en formación

## Secciones del sitio
- Inicio
- Sobre mí
- Habilidades
- Proyectos
- Contacto

## Estilo visual
- Minimalista
- Colores neutros
- Diseño simple y ordenado
